= troshka_workload_cclm_platform_addons

Applies day-2 operand configuration (mirrored from the Troshka source cluster) for:

* Advanced Cluster Management — `MultiClusterHub`
* Advanced Cluster Security — `Central` + `SecuredCluster`
* Kube Descheduler — `KubeDescheduler`
* Ansible Automation Platform — `AnsibleAutomationPlatform`

Runs on the **source** cluster only (after `troshka_workload_cclm_operators`).
ACS PVC storage class defaults to `cclm_odf_storage_class` (external Ceph RBD).
