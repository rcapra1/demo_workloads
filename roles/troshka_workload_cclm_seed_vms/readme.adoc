= troshka_workload_cclm_seed_vms

Creates `source-cluster` / `destination-cluster` namespaces and optionally imports a
demo VM into the source namespace for MTV live-migration exercises.

The seed VM is created from the cluster DataSource
`openshift-virtualization-os-images/rhel9` onto
`ocs-external-storagecluster-ceph-rbd-virtualization` (30Gi by default).

Set `cclm_seed_vm_run: false` to skip VM creation (student imports via MTV UI).
